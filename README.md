# Simple ATM (Java)

This is a minimal console-based ATM simulation written in Java. It lets you:

- Check balance
- Deposit funds
- Withdraw funds

The program keeps a single in-memory balance for demonstration purposes only.

## Prerequisites

- Java 17+ (or any recent Java version that can compile `Main.java`)

## Run

```bash
javac Main.java
java Main
```

Follow the on-screen menu to perform ATM operations.
